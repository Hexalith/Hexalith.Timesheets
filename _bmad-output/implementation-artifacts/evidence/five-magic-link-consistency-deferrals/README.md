# Five magic-link consistency receipts

`verification.json` records final commands/scopes and runtime identity outcomes. `post-review-suites/` contains final corrected executable receipts; the projection rerun intentionally covers all affected catalog classes. `initial-suites/` retains the complete broad run, including corrected failures, and its full 755-case projection pass. `focused/` and `review-fixes/` retain focused development/review checks.

`runtime/run-przq32wz/` is the successful unskipped final qualification. `baseline/`, `runtime-refusal/`, and `runtime-pre-baseline-failure/` retain earlier results without treating them as passes. Most JSON receipts are plain text; command logs, XML and the raw gateway capture are gzip-compressed with deterministic timestamps. No credential values are retained.
