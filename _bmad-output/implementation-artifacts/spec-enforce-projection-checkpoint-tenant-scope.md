## Intent

**Problem:** Timesheets projection folds accept a checkpoint from another tenant. A foreign Fresh checkpoint can mark evidence, reports, and ledger export previews ready even though its freshness does not certify the requested tenant.

**Approach:** Validate checkpoint tenant identity with ordinal equality before folding or returning a read model. Cover Time Entry evidence (full and incremental), evidence lists, period summaries, approved ledgers, both actual-report targets, both activity-catalog views, and capability projections. Reject mismatches with the existing projection-scope `InvalidOperationException` convention, including empty-history paths. Capability projection has no requested tenant argument, so validate against its selected issuance before constructing a model and retain the existing null result without issuance. Preserve matching-tenant freshness, parent-to-child checkpoint reuse, event folding, authorization defaults, and all persistence and hosting contracts.

</frozen-after-approval>
